# 📁 AI Sync & RFC Hub

Direktori ini menyimpan catatan **Request for Comments (RFC)** dan hasil diskusi kolaboratif lintas AI Council (**Antigravity, Claude, ChatGPT, DeepSeek, Kimi**).

Setiap kali perintah `/diskusikan [topik]` dijalankan di Antigravity, file RFC baru akan dibuat di folder ini sebagai arsip keputusan arsitektur proyek (*Architectural Decision Records / ADR*).
